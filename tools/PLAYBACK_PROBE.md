# 雷电“影视”播放验证工具

本地验证原型，仅在手动调用时操作模拟器，不修改影院配置，不删除片源，不创建定时任务。

已在雷电的在线设备 `emulator-5554`、影视 5.6.9 上验证连接、按页面控件选片和读取播放状态。设备编号和安装路径可通过参数指定。

## 单部影片自动验证

让影视停留在影片列表，确保目标影片名称可见且唯一，再调用：

```text
python tools/eggtv_player_probe.py --action trial --target "影片名称" --seconds 30 --output "报告路径.json"
```

工具点击该影片，每秒读取播放状态，观察结束后返回列表。影视当前版本进入影片详情时会自动开始播放。`--action inspect` 查看页面，`--action tap --target "屏幕文字或控件编号"` 点击唯一目标；也可用这些动作切换片源。

## 如何理解结果

- `first_progress_after_click_seconds`：从点击到确认播放器进度推进的时间，含采样间隔；不是精确首帧时间。
- `playback_progress_verified`：播放器报告正在播放且进度推进。不能据此证明画面、声音或电视解码完全正常。
- `source_verified`：试播结束时显示的站源与选片前的站源一致。无法确认或发生换源时，不能把成功归到原片源。
- `buffering_samples_after_first_progress`：确认播放进度后，采样中出现缓冲状态的次数；不是完整卡顿次数，可能遗漏短于采样间隔的停顿。
- `read_error_samples`：读取状态失败的采样数。检测工具失败不能算作片源失败。

报告不保存播放地址或请求头。起播前的加载与播放中的缓冲应分别看待。应用开启自动换源时，目前的结束站源核验不足以排除所有中途换源，正式评分需要进一步限制或追踪换源。

## 尚未实现

自动遍历全部片源、滚动选取多部影片、长时卡顿统计、每周计划任务、删除与恢复、网络异常识别及菜单发布均未实现。本工具用于验证路线可行性，不能直接承担无人值守片源管理。
